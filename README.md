Patitas Pa’ que las Quiero!

Un plataformas de acción en 2D, con desplazamiento lateral, obstáculos, proyectiles y combates basados en eventos de tiempo rápido (QTE).

El protagonista debe atravesar distintos escenarios para superar obstáculos, y evitar peligros. Durante su recorrido, tendrá que demostrar agilidad, resistencia y determinación para avanzar, superar y ¡vencer a la corona española!
