# Patitas Pa’ que las Quiero!

Un juego de **plataformas y acción en 2D**, con desplazamiento lateral, obstáculos, proyectiles y combates basados en eventos de tiempo rápido (**QTE**).

El protagonista deberá atravesar distintos escenarios, superar obstáculos y evitar toda clase de peligros. Durante su recorrido, tendrá que demostrar su **agilidad, resistencia y determinación** para seguir avanzando, enfrentarse a sus enemigos y, finalmente, **¡vencer a la Corona española!**
